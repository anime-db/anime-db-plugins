# animedb-shikimori

Официальный плагин-источник **[Shikimori](https://shikimori.io)** для AnimeDB —
заполнение карточек аниме метаданными, синхронизация статуса просмотра и виджеты
«связанное / похожее / новинки». Данные берутся из официального API Shikimori
(GraphQL и REST); для синхронизации используется OAuth.

## Возможности

- **Заполнение карточек и поиск.** Распознаёт аниме по названию и по ссылкам на
  Shikimori, работает анонимно, без авторизации. Заполняет поля карточки:
  - название и альтернативные названия;
  - описание (только русская локаль — Shikimori отдаёт единственное описание);
  - тип, число эпизодов, длительность;
  - даты выхода (премьера и окончание);
  - жанры, темы, демография;
  - студии;
  - обложка (постер);
  - галерея изображений (скриншоты аниме).

  Страны (`countries`) не заполняются: в API Shikimori нет поля «страна
  производства» (единственное похожее поле, `origin`, описывает первоисточник —
  мангу, ранобэ, игру и т. п., а не географию).
- **Синхронизация watch-листа.** Двусторонняя синхронизация статуса просмотра с
  вашим списком на Shikimori: локальные изменения уходят на Shikimori, изменения на
  Shikimori подтягиваются в каталог. Требует авторизации.
- **Виджеты** (по умолчанию выключены, включаются каждый отдельно на странице
  настроек виджетов):

  | Виджет    | Где      | Что показывает                                               |
  |-----------|----------|--------------------------------------------------------------|
  | `related` | карточка | связанные тайтлы (франшиза), отсортированные по дате выхода  |
  | `similar` | карточка | похожие тайтлы                                               |
  | `new`     | каталог  | новинки (при авторизации — без уже добавленных в ваш список) |

## Требования

- Хост-приложение AnimeDB (контракт плагинов `anime-db/plugin-contracts`
  предоставляется им в рантайме).
- PHP ≥ 8.1.

## Установка

Через маркет плагинов AnimeDB или установкой ZIP-архива вручную. Контрактные классы
даёт хост — `vendor/` в архив не входит.

## Настройка

На странице настроек плагина:

- **Эндпоинт API** — по умолчанию `https://shikimori.io`. Поле позволяет указать
  альтернативный хост API; оставьте пустым, чтобы использовать значение по умолчанию.
- **Авторизация Shikimori** — кнопка «Авторизоваться» запускает OAuth (Authorization
  Code + PKCE). Нужна только для синхронизации; для заполнения карточек и виджетов
  авторизация не требуется. Доступны повторная авторизация и отключение аккаунта.

Виджеты включаются отдельно, на странице настроек виджетов хоста — каждый своим
переключателем.

## Как это работает

- **Заполнение и виджеты** — анонимные чтения (обязателен только заголовок
  `User-Agent`). «Похожее» берётся из REST (`/api/animes/:id/similar` — в GraphQL его
  нет), остальное — из GraphQL.
- **Синхронизация** — запись статуса через REST v2 `user_rates`, чтение списка — через
  GraphQL `userRates`. На истёкший токен клиент прозрачно обновляет его и повторяет
  запрос; при окончательно недействительной сессии просит авторизоваться заново.
- **Ограничение частоты.** Shikimori ограничивает запросы (5 в секунду / 90 в минуту).
  Клиент сам держит ограничитель и на ответ `429` паузит запрос (уважая `Retry-After`),
  а не падает.
- **Токены** хранит хост, в своём сторе настроек плагина. OAuth-эндпоинты жёстко
  привязаны к `shikimori.io` и не зависят от поля «Эндпоинт API».

## Устройство

Плагин — это `manifest.json` + `src/` + `templates/` + `translations/` +
`plugin-routing.yaml`:

- **нет собственного DI-конфига, класса бандла и тегов** — хост сам регистрирует
  классы из `src/` как сервисы (включая `#[AsController]`-контроллеры) и тегирует их
  по реализованным контрактным интерфейсам;
- **`templates/`** — Twig-шаблоны, рендерятся через host-`Twig\Environment` под
  неймспейсом `@AnimedbShikimori`;
- **`translations/`** — переводы строк интерфейса плагина (`*.ru.yaml`, `*.en.yaml`);
- **`plugin-routing.yaml`** — собственные роуты плагина (страница настроек и OAuth),
  хост читает файл из корня плагина.

Флаги `features` в `manifest.json`: `filler` (заполнение + поиск), `sync`
(синхронизация), `related` / `similar` / `new` (виджеты, по умолчанию `false`).

## Разработка

```bash
composer install   # контракт + PHPUnit для IDE, статического анализа и локальных тестов
composer test
```

`anime-db/plugin-contracts` подключается из публичного VCS-репозитория (см.
`repositories` в `composer.json`); `composer install` работает без токена. В ZIP-сборку
не попадают `vendor/` (контракт даёт хост) и `tests/`.
