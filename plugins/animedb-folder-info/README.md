# animedb-folder-info

Официальный плагин AnimeDB типа `local`. Записывает описание тайтла и копию его обложки в
собственную папку записи: автоматически, массово со страницы настроек и по кнопке в карточке.

## Что делает

Виджет записи «Папка» (`folder`) при открытии карточки показывает состояние файлов плагина
в папке записи, ничего не записывая. Кнопка «Записать описание в папку» создаёт два файла:

- `animedb-info.html` — описание тайтла: самодостаточный HTML с inline-стилями, без
  скриптов и внешних ресурсов;
- `animedb-cover.<ext>` — копия обложки записи (расширение выбирает приложение: `jpg`, `png`
  или `webp`). Если у записи нет обложки или она в другом формате либо больше 5 МБ,
  обложка не записывается и в `animedb-info.html` её нет.

Плагин сам ничего не пишет на диск и не получает путей: имена файлов и содержимое он
передаёт приложению, а оно находит папку, проверяет права и пишет файлы атомарно.

## Автоматика

Переключатель «Заполнять автоматически» на странице настроек плагина **включён по умолчанию**
(в том числе после обновления с 0.1.0, пока значение не сохранено). Пока он включён, плагин
ставит фоновую задачу записи, когда:

- у записи появилась или сменилась папка: создание, скан, привязка, загрузка. Когда папку
  отвязали, задача не ставится;
- изменилось поле каталога, которое выводится в `animedb-info.html` (название,
  альтернативные названия, тип, жанры, темы, число серий, описание, даты, длительность,
  студии, страны), или обложка. Изменение остальных полей задачу не ставит.

Выключить автоматику можно на странице настроек плагина. Если приложение где-то не прислало
событие, файл остаётся устаревшим — его исправит «Заполнить все папки».

**Автоматика никогда не перезаписывает чужое или изменённое:** все её записи идут без
перезаписи, файл, отличающийся от записанного плагином, пропускается без ошибки. Перезаписать
такой файл можно только кнопкой «Перезаписать» в виджете записи.

## Заполнить все папки

Кнопка на странице настроек в фоне обходит записи, у которых есть своя папка, пакетами по 50 и
записывает файлы так же, как автоматика, без перезаписи. Работает и при выключенной
автоматике. Повторное нажатие начинает прогон заново, предыдущий останавливается. Пока идёт
прогон, фоновые задачи других плагинов выполняются между пакетами.

После прогона страница настроек показывает итог с датой:

- актуально — файлы записаны или уже совпадали;
- изменено вне AnimeDB — файл пропущен;
- нет своей папки;
- хранилище недоступно;
- запись запрещена — хранилище только для чтения или ещё не просканировано, просканируйте его.

## Что в `animedb-info.html`

Название, альтернативные названия, тип, число серий, длительность, даты премьеры и
окончания, студии, страны, жанры, темы, описание и обложка. Подписи — на языке запроса
(`en` или `ru`); названия жанров и тем берутся из переводов приложения.

Чего в файле нет: источников (ссылок), рейтинга, статуса просмотра, заметок, меток и
сведений о хранилище.

## Статусы виджета

- «Записано в папку» — файлы на диске совпадают с тем, что записал плагин;
- «Описание ещё не записано» — файла нет;
- «Файл изменён вне AnimeDB» — файл есть, но отличается от записанного плагином. Кнопка
  «Перезаписать» повторно записывает все файлы плагина поверх; без явного нажатия чужой
  файл не трогается;
- «У записи нет своей папки» — путь записи указывает на одиночный файл. Такие записи не
  поддерживаются, соседние файлы в родительской папке не создаются;
- «Хранилище недоступно» и «Хранилище только для чтения» — запись невозможна, файлы не
  создаются.

## Чего плагин не делает

- Не перезаписывает изменённые файлы ни автоматикой, ни массовым заполнением.
- Не пишет эпизоды и `.nfo`.
- Не удаляет файлы: они остаются в папке после удаления плагина или записи.

## Требования

Из `manifest.json`:

- ядро AnimeDB `>=0.0.1`;
- PHP `>=8.5`;
- `plugin-contracts` `^0.27.1`.

Языки интерфейса: `en`, `ru`.
