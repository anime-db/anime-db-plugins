# animedb-media-details

Официальный плагин AnimeDB типа `local`. Показывает на странице записи сводку характеристик
её файлов (контейнер, дорожки, субтитры).

## Что делает

Плагин получает список файлов записи через медиабиблиотеку приложения и разбирает каждый
файл средством анализа медиа, которое предоставляет приложение. Результат по каждому файлу
сохраняется в хранилище данных плагина: контейнер, длительность, битрейт, размер, видео-,
аудио- и прочие дорожки, субтитры. Разбор идёт в фоновой задаче, страница записи диск не
читает.

## Возможности

- Виджет записи «Характеристики файлов» (`summary`) с одной сводкой по записи, а не списком
  по файлам: количество файлов, суммарный размер, суммарная длительность, видеокодек,
  разрешение, частота кадров, число звуковых дорожек, языки звука и субтитров.
- Если у файлов разные значения поля, показываются до трёх различных значений и «и ещё N».
  Пометка «не у всех файлов» стоит у размера, длительности, числа звуковых дорожек, языков
  звука и языков субтитров. У видеокодека, разрешения и частоты кадров пометки нет: если
  видеодорожка есть не у всех файлов, значение показывается без оговорки. Файлы, которые не
  удалось разобрать, учитываются отдельной строкой.
- Первый разбор запускается при первом показе виджета. Фоновый разбор заново обрабатывает
  файл, если у него изменились размер или время изменения, сменилась версия средства анализа
  либо файл раньше не удалось разобрать; данные остальных файлов переиспользуются. Сам
  виджет ставит повторный разбор только при смене версии средства анализа; изменение размера
  или времени изменения замечает событие изменения файлов записи.
- Если у записи есть сохранённые данные, разбор перезапускается при изменении её файлов.
- Если средство анализа или хранилище недоступны, ранее сохранённые данные не затираются;
  виджет показывает сообщение («недоступно», «не удалось получить характеристики ни одного
  файла»).
- Ограничение: если хранилище файлов недоступно при самом первом разборе записи, плагин
  сохраняет состояние «файлов нет», и виджет показывает «в записи нет файлов», хотя файлы
  есть. Это состояние сохраняется до следующего изменения файлов записи.

## Требования

Из `manifest.json`:

- ядро AnimeDB `>=0.0.1`;
- PHP `>=8.5`;
- `plugin-contracts` `^0.25 || ^0.26`.

Для разбора нужно средство анализа медиа на стороне приложения. Языки интерфейса: `en`, `ru`.
