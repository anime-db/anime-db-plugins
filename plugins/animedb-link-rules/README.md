# animedb-link-rules

Официальный плагин AnimeDB типа `local`. Содержит только данные (`manifest.json`,
`link-rules.yaml`, `link-rules.examples.yaml`, `README.md`) и не содержит кода.

Правила задают нормализованную ссылку **только для сравнения** записей каталога:
отображаемая ссылка не меняется. Правила лишь переписывают строку адреса, в сеть плагин
не ходит и данные не заполняет.

## Сайты

Википедия (все языки, мобильная версия), ANN, syoboi, allcinema, AniList, AniDB, MAL,
Shikimori, World-Art, Кинопоиск, fansubs.ru.

## Ограничения

- Онлайн-разрешения нет: ни редиректов, ни переименований статей.
- Пользовательский `api_endpoint` плагина Shikimori правила не покрывают; покрыты только
  домены `shikimori.org`, `.one`, `.me`, `.io`.
- Формат пути Кинопоиска (`/film/N`, `/series/N`) не сверен с реальными данными; старый формат
  `/level/1/film/N/` не поддержан.
- Заголовки статей Википедии сравниваются как есть: `_` и пробел в заголовке правилами не
  сводятся.

## Примеры

Примеры «ссылка → нормализованная ссылка» (включая случаи, когда ни одно правило не
применяется) лежат в [`link-rules.examples.yaml`](link-rules.examples.yaml). Их исполняет
гейт `validate-plugin.php`: каждый пример должен дать ожидаемый результат, и у каждого
правила должен быть хотя бы один пример. Входные ссылки даны в виде после общих шагов
приложения (схема `https`, без `www.`, без `#…` и завершающего `/`, параметры запроса
отсортированы по имени).
