# animedb-myanimelist

Официальный плагин-источник **[MyAnimeList](https://myanimelist.net)** для AnimeDB —
поиск, распознавание ссылок и заполнение карточек аниме. Данные берутся из официального
MyAnimeList API v2 (REST/JSON), анонимно — без авторизации.

## Возможности

- **Поиск по названию.** Распознаёт аниме по названию через `GET /anime`. Длина запроса
  `q` ограничена MyAnimeList (подтверждено живыми запросами к API, не только документацией):
  - минимум **3 символа** — короче клиент не отправляет запрос вовсе и возвращает пустой
    результат (сам MyAnimeList на такой запрос отвечает HTTP 400 `invalid q`);
  - максимум **64 символа** — длиннее запрос обрезается до 64 символов (`mb_substr()`,
    то есть по символам, а не по байтам: 64-символьный запрос на японском, то есть 192
    байта в UTF-8, MyAnimeList принимает, а байтовое ограничение в 64 — отклонило бы его).
- **Распознавание ссылок.** Извлекает числовой id аниме из ссылки на MyAnimeList:
  `https://myanimelist.net/anime/{id}`, `https://myanimelist.net/anime/{id}/<slug>` и
  устаревшая форма `https://myanimelist.net/anime.php?id={id}` (поддомены допускаются).
  Ссылки на мангу (`/manga/{id}`) и прочие страницы не распознаются.
- **Заполнение карточки.** Через `GET /anime/{id}` заполняет:
  - название и альтернативные названия (японское и английское — как официальные,
    синонимы — без привязки к языку; у MyAnimeList нет русского названия);
  - описание (только английская локаль — синопсис MyAnimeList на английском, хвост вида
    `[Written by MAL Rewrite]` или `(Source: ...)` вырезается как редакционная пометка, а
    не часть текста);
  - жанры, темы, демографию (18+-жанры MyAnimeList — Hentai, Erotica, Ecchi — у них нет
    соответствия в словарях контракта, поэтому они отсутствуют и в жанрах, и в темах);
  - тип, число эпизодов, длительность серии (переводится из секунд в минуты округлением
    до ближайшей целой);
  - даты выхода (премьера и окончание) — см. «Как это работает» про сторож дат;
  - студии;
  - обложку и галерею изображений.

  Страны (`countries`) не заполняются: в запросе карточки нет поля «страна производства».

Синхронизация watch-листа (`SyncInterface`) в этой версии плагина не реализована —
манифест отражает это явно (`features.sync` = `false`).

## Требования

- Хост-приложение AnimeDB (контракт плагинов `anime-db/plugin-contracts` предоставляется
  им в рантайме).
- PHP ≥ 8.5.

## Установка

Через маркет плагинов AnimeDB или установкой ZIP-архива вручную. Контрактные классы даёт
хост — `vendor/` в архив не входит.

## Настройка

На странице настроек плагина — только блок «Аккаунт»:

- **Подключение аккаунта MyAnimeList** — кнопка «Подключить» запускает OAuth
  (Authorization Code + PKCE). Подключённый аккаунт не используется заполнением карточки
  (оно анонимно, см. выше) и синхронизацией (`features.sync` = `false` в этой версии) —
  задел на будущие версии. Доступны повторная авторизация и отключение аккаунта.
- Статус «Подключён» означает лишь, что токен сохранён, а не что он действителен —
  страница настроек его не проверяет.

У плагина нет поля адреса API: домен MyAnimeList фиксирован в коде (см. «Как это
работает» ниже).

## Как это работает

- **Поиск и заполнение карточки** — анонимные GET-запросы, обязателен заголовок
  `User-Agent`; без авторизации запрос несёт заголовок `X-MAL-CLIENT-ID` (публичный
  `client_id` этого приложения — секрета у приложения такого типа в MyAnimeList нет).
  Заполнение карточки не передаёт и не читает Bearer-токен — анонимный импорт каталога не
  привязывается к аккаунту пользователя.
- **Сторож дат.** `datePremiere` берётся от начала периода `start_date`, `dateEnd` — от
  конца периода `end_date` (неполная дата типа `YYYY` или `YYYY-MM` округляется вверх —
  до 31 декабря или до последнего дня месяца, а не до первого). Если после такого
  округления `dateEnd` оказывается раньше `datePremiere` (несовпадающие по полноте даты
  одной карточки), `dateEnd` не отдаётся (`null`), `datePremiere` остаётся: хост считает
  тайтл вышедшим при `dateEnd <= now` и бросает исключение при `dateEnd < datePremiere`.
- **Ограничение частоты.** Официальный лимит MyAnimeList не опубликован; на практике —
  не чаще примерно одного запроса в секунду. Плагин сам держит ограничитель (1 запрос в
  секунду, 60 в минуту) и на ответ `429` паузит запрос (уважая `Retry-After`), а не падает.
  Ограничитель — один общий экземпляр на все HTTP-запросы плагина.

## Устройство

Плагин — это `manifest.json` + `src/` + `templates/` + `translations/` +
`plugin-routing.yaml`:

- **нет собственного DI-конфига, класса бандла и тегов** — хост сам регистрирует классы из
  `src/` как сервисы (включая `#[AsController]`-контроллеры) и тегирует их по реализованным
  контрактным интерфейсам;
- **`templates/`** — Twig-шаблоны, рендерятся через host-`Twig\Environment` под
  неймспейсом `@AnimedbMyanimelist`;
- **`translations/`** — переводы строк интерфейса плагина (`*.ru.yaml`, `*.en.yaml`);
- **`plugin-routing.yaml`** — собственные роуты плагина (страница настроек и OAuth), хост
  читает файл из корня плагина;
- **`tests/Fixture/`** — живые ответы MyAnimeList API, использованные при разработке и
  тестировании (поиск, несколько карточек `GET /anime/{id}`, граничные значения `q`).

Флаги `features` в `manifest.json`: `filler` (заполнение + поиск), `sync`
(синхронизация, пока не реализована), `related` / `similar` / `new` (виджеты, в этой
версии не реализованы) — все, кроме `filler`, остаются `false`.

## Разработка

```bash
composer install   # контракт + PHPUnit для IDE, статического анализа и локальных тестов
composer test
```

`anime-db/plugin-contracts` устанавливается с Packagist; `composer install` работает без
токена. В ZIP-сборку не попадают `vendor/` (контракт даёт хост) и `tests/`.
