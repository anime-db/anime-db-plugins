# animedb-language-pack

Официальный языковой пакет AnimeDB: добавляет в приложение языки интерфейса помимо
встроенных русского и английского.

## Что внутри

```
animedb-language-pack/
├── manifest.json
├── README.md
└── translations/
    └── messages.de.yaml
```

Это плагин типа `translation` — декларативный ресурс без кода: ни `src/`, ни сервисов,
ни фич, только манифест и каталоги переводов. Приложение подключает каталоги пакета к
своему домену `messages` и добавляет объявленные локали в переключатель языка.

Отсюда и имя файла: `messages.<locale>.yaml`, а не `<plugin-id>.<locale>.yaml`, как у
плагинов фич. Пакет расширяет каталог ядра, а не возит свои строки.

## Языки

| Локаль | Строк | Качество                                    |
|--------|-------|---------------------------------------------|
| `de`   | 359   | машинный перевод, вычитки носителем не было |

Русский и английский каталоги ведёт автор проекта, они в состав пакета не входят.

**Про качество без обиняков:** переводы здесь машинные. Пакет существует прежде всего
как рабочий пример устройства плагина-перевода и как проверка того, что механизм
подключения локалей работает. Заявкой на полноценную поддержку языка он не является.

Нашли ошибку в переводе — исправление приветствуется.

## Установка

Через маркет плагинов в настройках приложения либо сайдлоадом ZIP-архива. После
установки язык появляется в переключателе на странице настроек.

Интерфейс окна приложения переводится целиком. **Нативная обвязка — заставка при
запуске, меню в трее и диалоги ошибок — остаётся на встроенном языке:** её набор языков
расширяется только релизом ядра, плагин на неё не влияет.

## Правка переводов

Требования к каталогам общие для всех плагинов репозитория и описаны в
[`.claude-docs/conventions.md`](../../.claude-docs/conventions.md): синтаксис
плейсхолдеров, запрет плюрализации, пустые значения, терминология. Часть из них
проверяет `tools/validate-plugin.php` на каждом pull request, часть остаётся на
совести автора перевода.

Перед правкой стоит прогнать валидатор:

```bash
php tools/validate-plugin.php plugins/animedb-language-pack
```
