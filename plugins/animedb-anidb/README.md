# animedb-anidb

Официальный плагин-источник **[AniDB](https://anidb.net)** для AnimeDB — поиск по названию
и распознавание ссылок, заполнение карточки.

## Возможности

- **Поиск по названию.** У API AniDB нет поиска по названию, поэтому плагин ищет по
  локальному дампу всех названий AniDB. Названия сравниваются после нормализации (регистр,
  пунктуация, пробелы). Если есть точные совпадения, отдаются только они; иначе — совпадения
  по началу названия. Подстрочных совпадений нет: заполнение карточки берёт первого
  кандидата без выбора и запоминает внешний id навсегда, поэтому случайное вхождение
  строки в чужое название недопустимо. Внутри уровня порядок такой: основное название,
  официальное, синоним, короткое, затем `aid` по возрастанию. Кандидат один на тайтл, его
  имя — основное название тайтла, даже если совпало другое.
- **Распознавание ссылок.** Извлекает числовой `aid` из ссылки на `anidb.net` или
  `www.anidb.net` (схемы `http` и `https`) в трёх формах:
  - `https://anidb.net/anime/{aid}`;
  - `https://anidb.net/a{aid}`;
  - `https://anidb.net/perl-bin/animedb.pl?show=anime&aid={aid}`.

  Прочие ссылки не распознаются.

- **Заполнение карточки.** По `aid` плагин получает карточку из API AniDB и заполняет поля:
  `title` (основное название), `alternativeNames`, `descriptions` (только `en`), `genres`,
  `themes`, `demographic`, `type`, `datePremiere`, `dateEnd`, `durationMinutes`,
  `episodesCount`, `studios`, `cover`. Поля `images` и `countries` не заполняются: в ответе
  AniDB их нет. Карточка берётся только через клиент с кэшем на 24 часа, лимитером и
  предохранителем бана: повторное заполнение той же карточки не делает запрос. Несуществующий
  `aid` даёт «не найдено»; прочие ошибки (в том числе действующий бан) пробрасываются. Если
  после округления `dateEnd` оказывается раньше `datePremiere`, `dateEnd` не отдаётся.
  Карточки `restricted="true"` API отдаёт целиком без логина, поэтому они заполняются так же,
  как остальные.

Синхронизация и виджеты в плагине не реализованы.

## Мапперы карточки

В `src/Mapping/` лежат чистые мапперы ответа AniDB (XML) в типы контракта. Заполнение карточки
собирает результат из них.

- **Названия** — только `/anime/titles/title` (названия эпизодов не берутся). `type="main"` —
  основное название, `kanareading` отбрасывается. `xml:lang` передаётся как локаль как есть;
  `x-jat` (ромадзи) и любые другие `x-*` дают локаль `null`.
- **Обложка** — только `/anime/picture`, URL `https://cdn-eu.anidb.net/images/main/<picture>`.
- **Тип** (`type` → `AnimeType`):

  | AniDB | AnimeType |
  | --- | --- |
  | `TV Series` | `Tv` |
  | `Movie` | `Movie` |
  | `OVA` | `Ova` |
  | `Web` | `Ona` |
  | `TV Special` | `Special` |
  | `Music Video` | `Music` |
  | `Other`, `Unknown`, любое другое | `null` (поле не заполняется) |

- **Даты** — неполная `startdate` дополняется до начала периода (`YYYY` → `YYYY-01-01`,
  `YYYY-MM` → `YYYY-MM-01`), неполная `enddate` — до конца (`YYYY` → `YYYY-12-31`,
  `YYYY-MM` → последний день месяца). Мусор даёт `null`.
- **Теги** → жанры, темы, демография по имени тега и таблице синонимов; теги со
  `localspoiler`/`globalspoiler` и неизвестные теги отбрасываются. Вес тега не учитывается:
  в AniDB вес 0 означает «без оценки» или «неявно применён через дочерний тег», а не
  «не применяется».
- **Описание** — ссылки `http://anidb.net/cr123 [Имя]` заменяются на `Имя`, хвост `Source: …`
  и строки `Note: …` вырезаются. Язык — `en`.
- **Число серий** — `episodecount`, если больше 0. **Длительность** — медиана `length`
  обычных серий (`<epno type="1">`). **Студии** — `creators/name[@type="Animation Work"]`.

## Откуда берутся названия

Плагин сам скачивает суточный дамп названий `anime-titles.dat.gz` с `anidb.net` и хранит его
в каталоге кэша плагина вместе с SQLite-индексом, который строится один раз на версию дампа
(`ETag`, а если его нет — `Last-Modified`). Дамп скачивается лениво, при первом поиске, и
**не чаще раза в сутки**: AniDB блокирует по IP за частые запросы одних и тех же данных.
Если свежего дампа нет, но есть старый, поиск идёт по старому. Сбой сети без ответа
повторяется не раньше чем через час.

Время последней попытки хранится в настройках плагина и записывается сразу по получении
ответа (любого, включая 304 и ошибки), до разбора тела.

### Ограничение

После неудачной загрузки или очистки каталога кэша **поиск может не работать до суток**:
следующая попытка скачать дамп разрешена не раньше чем через 24 часа после прошлой, даже
если файла дампа уже нет. Это сознательная цена защиты от блокировки.

## Разработка

```bash
composer install   # контракт + PHPUnit для IDE, статического анализа и локальных тестов
composer test
```

`anime-db/plugin-contracts` устанавливается с Packagist; `composer install` работает без
токена. В ZIP-сборку не попадают `vendor/` (контракт даёт хост) и `tests/`. Тесты не ходят в
сеть и работают на небольшом фрагменте дампа из `tests/Fixture/`.
