# animedb-worldart

Официальный плагин-источник **[World-Art](http://www.world-art.ru)** для AnimeDB — поиск по
названию и распознавание ссылок.

## Возможности

- **Распознавание ссылок.** Извлекает числовой `id` из ссылки на `world-art.ru` или
  `www.world-art.ru` (схемы `http` и `https`) ровно одной формы:
  `http://www.world-art.ru/animation/animation.php?id={id}`. Другие страницы тайтла
  (`animation_full_cast.php?id=` и т. п.), раздел `/cinema/` и нечисловой или неположительный
  `id` не распознаются.
- **Поиск по названию.** Запрос уходит на поиск сайта (раздел «аниме»), кодируется в
  `windows-1251`. Пустой запрос и запрос, в котором не осталось ни одной буквы или цифры
  (например, из одних иероглифов), не делают запроса к сайту и дают пустой список. Страницы
  выдачи не обходятся: один поиск — один запрос (плюс запрос карточки, если сайт сразу
  перенаправил на единственный результат; имя кандидата тогда — заголовок карточки, а сама
  карточка берётся через кэш карточки). Имя кандидата — название без хвоста `(год, страна, тип, N эп.)`; пометка сезона `[ТВ-N]`
  сохраняется. Поиск не кэшируется. Ответ сайта «недоступен» на поиск —
  ошибка, а не пустая выдача.
- **Кэш карточки — 24 часа.** Карточка хранится на диске в каталоге кэша плагина по id, в
  исходных байтах `windows-1251`; разбор идёт при каждом чтении. Ответ из кэша лимитер не
  проходит. В кэш попадает только карточка (заголовок тайтла и хотя бы одна пара «метка →
  значение»). «Не найдено» — `meta refresh` на `/not_connect.html` или на `/animation/`, а
  также страница первой карточки вместо запрошенной — не кэшируется: «нет тайтла» и «сайт
  недоступен» по ответу не различить.

Заполнение карточки, виджеты и синхронизация в плагине пока не реализованы.

## Порядок кандидатов — эвристика

Сайт сортирует выдачу по году по убыванию, а не по релевантности, и для запроса `naruto`
оригинальный сериал оказывается последним. Хост же берёт первого кандидата без выбора.
Поэтому плагин ставит вперёд кандидатов, у которых нормализованное название (русское или
строка выдачи под ним) совпало с нормализованным запросом, — по году возрастания (оригинал
раньше продолжений); остальные идут в порядке сайта. Нормализация: без пометок `[ТВ-N]`,
без учёта регистра, `ё` = `е`, знаки препинания как пробелы. Это эвристика, а не гарантия, что
первый кандидат — нужный тайтл.

## Ограничения сайта

- Сайт работает **только по `http://`** (HTTPS нет). При работе через прокси ядра прокси видит
  содержимое запросов.
- Лимит — **1 запрос в 2 секунды** на весь плагин. Лимитер межпроцессный: слот
  резервируется на диске в каталоге кэша плагина под `flock`, сон до слота идёт вне замка;
  слот дальше 20 с не резервируется — запрос завершается ошибкой.
- Страницы приходят в `windows-1251` и разбираются из исходных байтов, без перекодирования.

## Разработка

```bash
composer install   # контракт + PHPUnit для IDE, статического анализа и локальных тестов
composer test
```

Тесты не ходят в сеть. В `tests/Fixture/` лежат страницы сайта в исходных байтах
`windows-1251`: описание тайтла заменено заглушкой, ссылки на сторонние ресурсы убраны, кроме
блока ссылок карточки на другие базы.
